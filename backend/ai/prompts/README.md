# 프롬프트

기능별 프롬프트를 이 폴더에 `기능명.md` 파일로 둡니다.

| 파일 | 기능 |
|---|---|
| talent_discovery.md | 숨은 재능 발굴 |
| agreement.md | 교환 범위 합의 도우미 |
| breakdown.md | 부탁 쪼개기 |
| path.md | 목표 기반 교환 경로 |
| match_reason.md | 매칭 추천 이유 |
| review_analysis.md | 후기 분석·기여도 점수 |

`ai/mocks/기능명.json`에는 같은 기능의 예시 응답을 둡니다. `AI_MOCK=true`일 때 이 응답을 씁니다.
