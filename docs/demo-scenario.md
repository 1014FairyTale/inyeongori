# 데모 시나리오

재능이 없다던 사람이 자기 경험으로 토큰을 벌기까지를 약 6분 동안 보여 줍니다. 새로 가입하는 사용자(창 A)와 데모 요청자(창 B), 두 브라우저 창으로 진행합니다. 등장인물은 모두 가상입니다.

## 0. 준비 (발표 10분 전)

```bash
docker compose up -d
docker compose exec backend python -m seed.seed --reset --yes
```

시드를 넣으면 가상 인물 12명, 재능 상품 16개, 완료된 거래와 후기 12건, 진행 중인 거래 2건이 생깁니다.

브라우저 창 두 개를 http://localhost:3000 으로 엽니다. 휴대폰 크기로 보는 것을 권합니다.

- 창 A(일반 창): 로그아웃 상태로 둡니다. 발표 중에 새로 가입합니다.
- 창 B(시크릿 창): `demo@example.com`과 데모 비밀번호로 로그인합니다. 비밀번호는 README의 데모 계정 항목에 있습니다.

`http://localhost:8000/api/v1/health`가 `"ai_mock": false`인지 확인합니다. 실제 AI가 불안하면 맨 아래 비상 계획을 따릅니다.

## 1. 문제 제기 (30초, 창 A)

"많은 사람이 모임 총무, 과외, 행사 준비 같은 경험을 재능이라고 생각하지 못합니다."

- 첫 화면을 보여 주고 "AI가 내 재능 찾아 주기"를 눌러 가입합니다.
- 이메일은 `minsu@example.com`, 닉네임은 `재능없는민수`로 합니다.
- 헤더의 100토큰을 가리키며 "가입하면 현금 대신 100토큰을 받습니다"라고 말합니다.

## 2. 숨은 재능 찾기 (1분 30초, 창 A)

아래 문장을 미리 복사해 둡니다.

- 자기소개: `저는 딱히 잘하는 게 없는 평범한 회사원이에요. 동네 독서 모임 총무를 1년 했어요.`
- 최근에 맡았던 역할: `모임 총무, 1박 2일 여행 준비도 제가 다 했어요`
- 친구들이 자주 부탁하는 것: `주변에서 발표 PPT 좀 봐 달라고 해요`
- 자신 있는 도구: `엑셀, 노션은 자신 있어요`

"AI로 내 재능 찾기"를 누르면 약 5초 뒤 후보가 나옵니다.

- 후보마다 근거("총무 일에는 보통 회비 정산이 포함돼요")와 확인 질문이 있다는 점을 보여 줍니다.
- "AI의 추론은 확정이 아니고, 본인이 확인한 것만 저장된다"고 설명합니다.
- 엑셀 정산 후보는 맞아요, 하나는 수정(이름 고치기), 하나는 아니에요를 누릅니다.
- 확정한 재능을 마켓에 올립니다. 가격 `25`, 예상 시간 `30`.

## 3. 매칭과 합의 도우미 (1분 30초, 창 B)

- 하단 찾기 탭에서 `모임 회비 정산을 엑셀로 하고 싶어요`를 입력하고 "AI로 추천받기"를 누릅니다.
- 일치도와 AI 추천 이유, 평점과 활동 이력이 반영된 순서를 보여 줍니다. 방금 가입한 재능없는민수가 추천에 나옵니다. 보이지 않으면 마켓에서 `정산`으로 검색합니다.
- 민수의 상품에서 "25토큰으로 요청하기"를 누릅니다.
- 합의 도우미에 `회비 정산표 좀 봐주세요`를 쓰고 "AI로 조건 정리하기"를 누릅니다. AI가 범위를 정리하고 빠진 조건(분량, 수정 횟수 등)을 보기로 묻습니다. 보기를 하나씩 고릅니다.
- "봐 주세요처럼 모호한 부탁 때문에 생기는 갈등을 미리 막는다"고 설명합니다.
- "요청서에 채우기", "요청 보내기" 순서로 누릅니다.

## 4. 토큰 거래 (1분, 창 A와 창 B)

- 창 A의 거래 탭에서 내 차례 표시를 확인하고 합의서에 동의합니다.
- 창 B의 토큰이 75로 줄어듭니다. 25토큰은 도움이 끝날 때까지 보류됩니다.
- 두 창에서 각각 완료 확인을 누르면 창 A의 토큰이 125가 됩니다.

## 5. 후기 분석과 보너스 (1분, 창 B에서 창 A)

창 B의 거래 화면 아래에서 후기를 남깁니다.

- 별점 5개
- 좋았던 점: `SUMIF로 자동 합계 내는 법까지 알려 주셔서 다음 달부터 혼자 쓸 수 있게 됐어요. 템플릿 파일도 따로 보내 주셨어요.`
- 아쉬운 점: `시간이 조금 짧았어요`

AI가 기여도 점수와 판단 근거를 보여 주고, 민수에게 보너스 5토큰(25토큰의 20%)이 지급됩니다. "보너스 계산 과정 보기"를 열어 "AI는 점수만 내고 금액은 규칙으로 계산한다, 같은 사람끼리 반복 거래하면 줄어든다"고 설명합니다.

창 A를 새로고침하면 130토큰이 보입니다. "재능이 없다던 민수가 자기 경험으로 토큰을 벌었습니다."

## 6. 마무리 (30초, 창 B)

부탁 쪼개기 화면의 목표 경로에서 `공모전에 나가고 싶어요`를 입력하면 기획, 디자인, 발표 순서와 단계별 추천 제공자가 나옵니다. 생성에 약 10초가 걸리니 시간이 부족하면 미리 만들어 두고 지난 계획에서 엽니다.

## 비상 계획

| 상황 | 대응 |
|---|---|
| AI 응답이 느리거나 무료 사용 한도 오류가 남 | 잠시 후 다시 시도합니다. 계속 안 되면 `.env`에서 `AI_MOCK=true`로 바꾸고 `docker compose up -d --force-recreate backend` 후 시드를 다시 넣습니다. 고정 예시로 모든 흐름이 돌아갑니다 |
| 매칭에 민수가 나오지 않음 | 마켓에서 `정산`으로 검색해 상품을 찾습니다 |
| 화면이 이상함 | `docker compose restart frontend` |
| 처음부터 다시 | `docker compose exec backend python -m seed.seed --reset --yes` 후 새로고침하고 다시 로그인합니다 |
