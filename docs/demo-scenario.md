# 데모 시나리오 — "재능이 없다던 학생이 재능으로 토큰을 벌기까지"

**약 6분.** 새로 가입하는 학생(A)과 데모 요청자(B), 두 창으로 진행해요.
모든 인물·학교는 가상이에요.

---

## 0. 준비 (발표 10분 전)

```bash
docker compose up -d
docker compose exec backend python -m seed.seed --reset --yes
```

- 시드: 가상 학생 12명, 재능 상품 16개, 완료된 거래·후기 12건, 진행 중 거래 2건
- 브라우저 창 2개 (둘 다 http://localhost:3000, 휴대폰 크기 추천)
  - **창 A (일반 창)**: 로그아웃 상태 — 발표 중에 새로 가입해요
  - **창 B (시크릿 창)**: `demo@example.com` / 데모 비밀번호로 로그인 (README '데모 계정')
- 확인: `http://localhost:8000/api/v1/health` 가 `"ai_mock": false` (실제 AI) 인지
- 실제 AI가 불안하면 → 아래 **비상 계획** 참고

## 1. 문제 제기 (30초) — 창 A

> "대학생들은 동아리 총무, 과외, 행사 준비 같은 경험을 '재능'으로 생각하지 못해요."

- 첫 화면의 **"저는 재능이 없어요" 정말 그럴까요?** 를 보여 줘요.
- **✨ AI가 내 재능 찾아 주기** 클릭 → 가입
  - 이메일: `minsu@example.com` / 닉네임: `재능없는민수` / 학교 `한빛대` / 전공 `경영학`
- 헤더에 **🪙 100** — "가입하면 현금 대신 100토큰을 받아요."

## 2. 숨은 재능 발굴 (1분 30초) — 창 A

입력 (미리 복사해 두세요):
- 자기소개: `저는 딱히 잘하는 게 없는 평범한 경영학과 2학년이에요. 동아리 총무를 1년 했어요.`
- 최근에 맡았던 역할: `동아리 총무, MT 준비도 제가 다 했어요`
- 친구들이 자주 부탁하는 것: `친구들이 과제 PPT 좀 봐 달라고 해요`
- 자신 있는 도구: `엑셀, 노션은 자신 있어요`

→ **✨ AI로 내 재능 찾기** (약 5초, 로딩 문구가 바뀌어요)

포인트:
- 후보마다 **근거**("총무 업무에는 보통 회비 정산이 포함돼요")와 **확인 질문**이 있어요.
- "AI 추론은 확정이 아니에요. 본인이 확인한 것만 저장돼요."
- 첫 후보(엑셀 정산 관련) → **맞아요**, 하나는 **수정**(이름을 고쳐 보기), 하나는 **아니에요**
- **'○○' 마켓에 올리기** → 가격 `25`, 예상 시간 `30` → **등록하기**

## 3. 매칭 + 합의 도우미 (1분 30초) — 창 B

- 하단 **🔎 찾기** → `동아리 회비 정산을 엑셀로 하고 싶어요` → **✨ AI로 추천받기**
  - 일치도, **AI 추천 이유**, 평점·활동 이력이 반영된 순서를 보여 줘요.
  - 방금 가입한 **재능없는민수**가 추천에 나오는 걸 보여 줘요. (안 보이면 마켓 검색 `정산`으로 찾아도 돼요)
- 민수의 상품 → **25토큰으로 요청하기**
- 합의 도우미에 `회비 정산표 좀 봐주세요` → **✨ AI로 조건 정리하기**
  - AI가 범위를 정리하고 빠진 조건(분량, 수정 횟수 등)을 **보기 버튼**으로 물어봐요 → 보기 하나씩 클릭
  - "'봐주세요'처럼 모호한 부탁 때문에 생기는 갈등을 미리 막아요."
- **요청서에 채우기** → **요청 보내기**

## 4. 토큰 거래 (1분) — 창 A ↔ 창 B

- 창 A: 하단 **거래** → **내 차례** 표시 → 합의서 확인 → **합의서에 동의하기**
  - 창 B 헤더 토큰이 **75**로 줄어요 (25토큰 **보류**). "돈 대신 토큰, 도움이 끝날 때까지 안전하게 맡아 둬요."
- 창 A, 창 B 각각 **완료 확인** → 창 A 헤더 **125** (지급)

## 5. AI 후기 분석 + 보너스 (1분) — 창 B → 창 A

- 창 B: 거래 화면 아래 **후기 남기기**
  - ★★★★★
  - 좋았던 점: `SUMIF로 자동 합계 내는 법까지 알려 주셔서 다음 학기에도 혼자 쓸 수 있게 됐어요. 템플릿 파일도 따로 보내 주셨어요.`
  - 아쉬운 점: `시간이 조금 짧았어요`
- AI가 **기여도 점수**와 **판단 근거**를 보여 주고 → **🎁 보너스 5토큰** (25토큰의 20%)
- **보너스 계산 과정 보기** — "AI는 점수만, 금액은 규칙으로. 같은 사람끼리 반복 거래하면 줄어들어요."
- 창 A 새로고침 → **130토큰**. "재능이 없다던 민수가 자기 경험으로 토큰을 벌었어요."

## 6. 마무리 (30초) — 창 B

- **✂️ 부탁 쪼개기 → 🧭 목표 경로**: `공모전에 나가고 싶어요` → 기획 → 디자인 → 발표 순서와 **단계별 추천 제공자**
  - 시간이 없으면 발표 전에 미리 만들어 두고 **지난 계획**에서 열어요 (생성에 약 10초).

## 비상 계획

| 상황 | 대응 |
|---|---|
| AI 응답이 느리거나 "무료 사용 한도" 에러 | 잠시 후 **다시 시도**. 계속 안 되면 `.env`에서 `AI_MOCK=true` → `docker compose up -d --force-recreate backend` → 시드 다시 넣기 (고정 예시로 모든 흐름이 돌아가요) |
| 매칭에 민수가 안 나옴 | 마켓에서 `정산` 검색으로 상품을 찾아 진행 |
| 화면이 이상함 | `docker compose restart frontend` |
| 처음부터 다시 | `docker compose exec backend python -m seed.seed --reset --yes` 후 브라우저 새로고침·재로그인 |
