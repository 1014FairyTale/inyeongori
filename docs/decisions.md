# 결정 사항

만들면서 정한 정책과 구현 방식을 모아 둔 표예요. 번호가 있는 항목(D1~D8)은 기획 단계에서 정한 것이고, `—`는 개발하면서 정한 것이에요. 정책 수치는 `backend/app/core/constants.py`와 같아야 하니, 한쪽을 바꾸면 다른 쪽도 함께 고쳐요.
